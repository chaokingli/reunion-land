# 《团圆大富翁》游戏规则 v1.0

> 中秋主题 · 儿童友好 · 大富翁简化版棋盘游戏
> 名称：团圆大富翁（Reunion Land / Zuhause-Spiel）
> 适用：2–4 名小朋友，6–12 岁
> 目标：**好玩、不吓人（无淘汰）、轻度益智**（计数、加减法、中秋文化、三语词汇）

---

## 1. 游戏概述

| 项目 | 说明 |
|---|---|
| 类型 | 回合制棋盘游戏（Monopoly/大富翁简化版） |
| 棋盘 | 10×10 环形棋盘，共 40 格 |
| 玩家数 | 2–4 人 |
| 一局时长 | 约 10–15 分钟 |
| 游玩模式 | ① 本地双人（同屏幕交替） ② 在线双人（WebSocket） ③ AI 伙伴（"兔姐"）可填充至 4 人 |
| 胜利条件 | 最先买齐 3 个灯笼（团圆成功） |
| 设计原则 | 答错不惩罚、不淘汰、不欠债、有提示 |

## 3. 起始条件

- 每位玩家：**100 月亮币**、1 个棋子（玉兔 / 灯笼 / 嫦娥 / 月亮），站在"团圆门"。
- 骰子：标准 6 面，步骤范围 **2–6**（儿童版不掷 1，节奏更顺）。
- 难度两档：
  - **小月（初级）**：数学 ≤ 15（如 7+6）；灯谜/知识初级。
  - **满月（进阶）**：数学 ≤ 40（如 18+27）；题目进阶。
- 每人有 **1 次"兔子提示"**：可让兔姐排除一个错误选项。

---

## 4. 一局流程

1. 当前玩家掷骰（2–6），棋子顺时针移动。
2. 执行所落格子的效果：
   - **灯笼位**：可花 50 买下（获得灯笼卡）。可选择不买 → 格子保留给其他玩家。
   - **问答类（灯谜/知识/数学）**：弹出三选一。答对得奖励；答错不惩罚。可点"兔子提示"排除一个错误选项后再选。
   - **移动类**：兔子洞 +4、月亮井 +6、秋风 −4。
   - **收益类**：直接得对应月亮币。
3. 回合结束，轮到下一位玩家。

### 租金规则（大富翁式互动）
- 落在**别人买下的灯笼位**：付 **10** 月亮币租金。
- 不够付？ → **免费通过，欠不了账**（儿童友好，永不淘汰）。
- 经过任一次"团圆门"：所有人 +50。

### 胜负
- **率先买齐 3 个灯笼 → "团圆成功"！胜利**。
- 若 40 回合无人获胜：灯笼多者胜；灯笼同数比月亮币；仍平 → 再赛 10 回合。
- 没有任何玩家出局机制。

## 5. 益智内容设计（轻度、可跳过式）

| 类别 | 数量 | 内容示例（中文版） |
|---|---|---|
| 灯谜（3 选 1） | 18 题 | "圆圆亮在天，嫦娥和兔伴" → 答：月亮 |
| 知识（3 选 1） | 24 题 | "中秋节是农历几月几号？" → 八月十五 |
| 数学（自动生成） | 不限 | 6+8=？（选项含一个干扰项） |

- 三选一而非填空：5 岁孩子看图文也能玩；答错无惩罚。
- 每种题目在 **zh_CN / en / de** 三语各有一个原生版本（谜语用"同主题等效谜"，不硬翻双关语）。
- AI 允许参与：服务器端可用 LLM 辅助**出题翻译与谜语生成**（开发工具），运行时默认离线规则库即可玩。

---

## 6. AI 伙伴"兔姐"（Tuni）

1. **AI 对手**：可加入 1–3 只 AI 兔（单人、双人在线均可补满桌）。策略本地规则实现：
   - 能买且余额 ≥55 时买灯笼；
   - 问答正确率 ~70%（保证小朋友能赢）；
   - 行动有 0.5–1.5s 延迟，配"兔子表情"动画，不抢人节奏。
2. **提示功能**：每人每局 1 次"问兔子" → 排除一个错误选项。
3. **可选 LLM 接入（可选功能，默认关闭）**：
   - 环境变量 `LLM_BASE_URL / LLM_API_KEY / LLM_MODEL` 配置后，
   - 支持：① 出题翻译（zh→en/de） ② 谜语生成（开发工具）③ 提示话术更生动。
   - 无网络/无 key 时自动回落到本地规则，游戏仍可完整运行。

---

## 7. 多语言

- 界面、棋子、格子文字、题目、AI 提示语：**简体中文 / 英语 / 德语**。
- 每玩家独立语言选择（可混桌，如中英小朋友一起玩）。
- 所有 UI 字符串与题库均按语言存储；未翻译内容用中文兜底（不做运行时机器翻译）。
